###  Key Concepts  
  
### [ 2.1 Linear Functions ](<2-1-linear-functions>)

  * The ordered pairs given by a linear function represent points on a line.
  * Linear functions can be represented in words, function notation, tabular form, and graphical form. See [Example 1](<2-1-linear-functions>).
  * The rate of change of a linear function is also known as the slope.
  * An equation in the slope-intercept form of a line includes the slope and the initial value of the function.
  * The initial value, or _y_ -intercept, is the output value when the input of a linear function is zero. It is the _y_ -value of the point at which the line crosses the _y_ -axis.
  * An increasing linear function results in a graph that slants upward from left to right and has a positive slope.
  * A decreasing linear function results in a graph that slants downward from left to right and has a negative slope.
  * A constant linear function results in a graph that is a horizontal line.
  * Analyzing the slope within the context of a problem indicates whether a linear function is increasing, decreasing, or constant. See [Example 2](<2-1-linear-functions>).
  * The slope of a linear function can be calculated by dividing the difference between _y_ -values by the difference in corresponding _x_ -values of any two points on the line. See [Example 3](<2-1-linear-functions>) and [Example 4](<2-1-linear-functions>).
  * The slope and initial value can be determined given a graph or any two points on the line.
  * One type of function notation is the slope-intercept form of an equation.
  * The point-slope form is useful for finding a linear equation when given the slope of a line and one point. See [Example 5](<2-1-linear-functions>).
  * The point-slope form is also convenient for finding a linear equation when given two points through which a line passes. See [Example 6](<2-1-linear-functions>).
  * The equation for a linear function can be written if the slope mm and initial value bb are known. See [Example 7](<2-1-linear-functions>), [Example 8](<2-1-linear-functions>), and [Example 9](<2-1-linear-functions>).
  * A linear function can be used to solve real-world problems. See [Example 10](<2-1-linear-functions>) and [Example 11](<2-1-linear-functions>).
  * A linear function can be written from tabular form. See [Example 12](<2-1-linear-functions>).

### [ 2.2 Graphs of Linear Functions ](<2-2-graphs-of-linear-functions>)

  * Linear functions may be graphed by plotting points or by using the _y_ -intercept and slope. See [Example 1](<2-2-graphs-of-linear-functions>) and [Example 2](<2-2-graphs-of-linear-functions>).
  * Graphs of linear functions may be transformed by using shifts up, down, left, or right, as well as through stretches, compressions, and reflections. See [Example 3](<2-2-graphs-of-linear-functions>).
  * The _y_ -intercept and slope of a line may be used to write the equation of a line.
  * The _x_ -intercept is the point at which the graph of a linear function crosses the _x_ -axis. See [Example 4](<2-2-graphs-of-linear-functions>) and [Example 5](<2-2-graphs-of-linear-functions>).
  * Horizontal lines are written in the form, f(x)=b.f(x)=b. See [Example 6](<2-2-graphs-of-linear-functions>).
  * Vertical lines are written in the form, x=b.x=b. See [Example 7](<2-2-graphs-of-linear-functions>).
  * Parallel lines have the same slope.
  * Perpendicular lines have negative reciprocal slopes, assuming neither is vertical. See [Example 8](<2-2-graphs-of-linear-functions>).
  * A line parallel to another line, passing through a given point, may be found by substituting the slope value of the line and the _x_ \- and _y_ -values of the given point into the equation, f(x)=mx+b,f(x)=mx+b, and using the bb that results. Similarly, the point-slope form of an equation can also be used. See [Example 9](<2-2-graphs-of-linear-functions>)**.**
  * A line perpendicular to another line, passing through a given point, may be found in the same manner, with the exception of using the negative reciprocal slope. See [Example 10](<2-2-graphs-of-linear-functions>) and [Example 11](<2-2-graphs-of-linear-functions>).
  * A system of linear equations may be solved setting the two equations equal to one another and solving for x.x. The _y_ -value may be found by evaluating either one of the original equations using this _x_ -value.
  * A system of linear equations may also be solved by finding the point of intersection on a graph. See [Example 12](<2-2-graphs-of-linear-functions>) and [Example 13](<2-2-graphs-of-linear-functions>).

### [ 2.3 Modeling with Linear Functions ](<2-3-modeling-with-linear-functions>)

  * We can use the same problem strategies that we would use for any type of function.
  * When modeling and solving a problem, identify the variables and look for key values, including the slope and _y_ -intercept. See [Example 1](<2-3-modeling-with-linear-functions>).
  * Draw a diagram, where appropriate. See [Example 2](<2-3-modeling-with-linear-functions>) and [Example 3](<2-3-modeling-with-linear-functions>).
  * Check for reasonableness of the answer.
  * Linear models may be built by identifying or calculating the slope and using the _y_ -intercept.
  * The _x_ -intercept may be found by setting  y=0, y=0, which is setting the expression  mx+b mx+b equal to 0.
  * The point of intersection of a system of linear equations is the point where the _x_ \- and _y_ -values are the same. See [Example 4](<2-3-modeling-with-linear-functions>).
  * A graph of the system may be used to identify the points where one line falls below (or above) the other line.

### [ 2.4 Fitting Linear Models to Data ](<2-4-fitting-linear-models-to-data>)

  * Scatter plots show the relationship between two sets of data. See [Example 1](<2-4-fitting-linear-models-to-data>).
  * Scatter plots may represent linear or non-linear models.
  * The line of best fit may be estimated or calculated, using a calculator or statistical software. See [Example 2](<2-4-fitting-linear-models-to-data>).
  * Interpolation can be used to predict values inside the domain and range of the data, whereas extrapolation can be used to predict values outside the domain and range of the data. See [Example 3](<2-4-fitting-linear-models-to-data>).
  * The correlation coefficient, r,r, indicates the degree of linear relationship between data. See [Example 5](<2-4-fitting-linear-models-to-data>).
  * A regression line best fits the data. See [Example 6](<2-4-fitting-linear-models-to-data>).
  * The least squares regression line is found by minimizing the squares of the distances of points from a line passing through the data and may be used to make predictions regarding either of the variables. See [Example 4](<2-4-fitting-linear-models-to-data>).
